■ 導入手順 / Setup
──────────────────────────────────────────────────────────────────────────────────

【UnityPackage の場合 / UnityPackage】
1. Unity プロジェクトに UniVRM をインポート / Import UniVRM into your Unity project
2. 本 UnityPackage をインポート (Assets > Import Package > Custom Package)
   / Import this UnityPackage (Assets > Import Package > Custom Package)
3. 以下のいずれかの方法で利用する / Use either of the following methods:
   【方法A / Option A】Kizuna_AI_KAMATTE.unity を開く（セットアップ済みシーンをそのまま使用）
   / Open Kizuna_AI_KAMATTE.unity (use the pre-configured scene as-is)
   【方法B / Option B】Kizuna_AI_KAMATTE.prefab をシーンにドラッグ＆ドロップで配置する
   / Drag & drop Kizuna_AI_KAMATTE.prefab into your scene

【VRM 単体の場合 / VRM Only】
1. VRM 1.0 に対応したアプリケーションに Kizuna_AI_KAMATTE.vrm を読み込む
   / Load Kizuna_AI_KAMATTE.vrm in a VRM 1.0 compatible application
   ※ 下記「VRM 1.0 互換性について」を必ずご確認ください
   / Please check "VRM 1.0 Compatibility" below

■ VRM 1.0 互換性について / VRM 1.0 Compatibility
──────────────────────────────────────────────────────────────────────────────────

本モデルは VRM 1.0 形式です。VRM 1.0 は比較的新しい規格であり、
多くのアプリケーションがまだ VRM 0.x のみ対応のため、
VRM 1.0 ファイルを正常に読み込めない場合があります。

This model uses the VRM 1.0 format. VRM 1.0 is a relatively new
specification, and many applications still only support VRM 0.x.
This file may not load correctly in those applications.

ご利用前に、お使いのアプリケーションが VRM 1.0 に対応しているか
必ずご確認ください。
Please verify that your application supports VRM 1.0 before use.

■ 注意事項 / Notes
──────────────────────────────────────────────────────────────────────────────────

- MToon シェーダーの制限により、透明部分の模様のスクロール
  (動画テクスチャ) には対応していません。
  Due to MToon shader limitations, scrolling patterns on transparent
  areas (video textures) are not supported.
